# تثبّت | Tathabbut

محرّك تحقق مُسنَد للمحتوى الإسلامي: يستخرج الادعاءات الشرعية من نص، ويسترجع
النص المعتمد، ويُصدر لكل ادعاء حكماً **بقواعد حتمية** لا بالنموذج اللغوي.

> **نسخة البداية (Pre-challenge baseline):** هذه الشفرة أُنشئت قبل أيام التحدي
> (4–6 أكتوبر 2026) وتُوثَّق هنا نسخةً للبداية وفق دليل المشارك. الوسم: `v0-baseline`.

## التشغيل المحلي

```bash
cd backend
./setup.sh                               # بيئة افتراضية + تثبيت + فهرس + اختبارات
source .venv/bin/activate
uvicorn app.main:app --reload --port 8000
```

جرّب:

```bash
curl -s -X POST localhost:8000/verify -H 'Content-Type: application/json' \
  -d '{"text":"قال رسول الله ﷺ: «اطلبوا العلم ولو في الصين». وقال تعالى: ﴿ومن يتوكل على الله فهو حسبه ونعم الوكيل﴾"}'
```

واجهة التوثيق التفاعلية: http://localhost:8000/docs

### الواجهة (Next.js)

في نافذة ثانية، والمحرّك يعمل:

```bash
cd frontend
npm install
npm run dev          # http://localhost:3000
```

التفاصيل في `frontend/README.md`.

### BGE-M3 (تضمين دلالي كامل)

```bash
./setup.sh bge-m3                        # يحمّل النموذج (~2.3GB) أول مرة
```

### النص القرآني الكامل

المصحف كاملاً (Tanzil simple-clean، 6236 آية) مضمَّن في `data/quran/quran_full.json`، ويُستخدم تلقائياً عند بناء الفهرس.
لإعادة تنزيله:

```bash
python scripts/fetch_quran.py            # يحفظ في data/raw/quran_full.json
python scripts/build_index.py
```

## الأحكام

| code | الحكم | القاعدة |
|---|---|---|
| `VERIFIED` | موثّق | آية مطابقة حرفياً (ولو عبر آيات متتالية)، أو حديث مطابق بدرجة «صحيح/حسن» مسجّلة في المصدر |
| `NOT_AUTHENTIC` | لا يصح | حديث مطابق ودرجته المسجّلة ضعيف/موضوع/باطل/لا أصل له |
| `ALTERED` | مُحرَّف | اقتباس قرآني مطابق جزئياً (≥60%) مع فروق حرفية تُعرض كلمة بكلمة |
| `NO_ORIGIN` | لا أصل له في المصادر المعتمدة | لا نص مطابق في الفهرس (ليس حكماً بالوضع) |
| `DISPUTED` | خلافي | تعارض أحكام المحدّثين، أو مسألة اجتهادية (المستوى ج) |
| `REFER` | إحالة | حالة شخصية (المستوى د): امتناع قبل أي استرجاع أو توليد |
| `NEEDS_REVIEW` | يتطلب مزيد تحقق | مطابقة جزئية، أو لا درجة مسجّلة، أو مصدر لم يُراجع |

## البنية

```
backend/app/core/
  arabic.py      تطبيع عربي + تجذير خفيف + كلمات وظيفية
  extractor.py   استخراج الادعاءات + تصنيف المستويات (أ–د)
  embedder.py    BGE-M3 أو TF-IDF حرفي + إسقاط SVD
  index.py       BM25 مُتجَّه (مصفوفة متفرقة) + بحث متجهي دقيق + دمج RRF
  align.py       محاذاة حرفية حتمية + الفروق
  judge.py       قواعد الحكم الحتمية
  pipeline.py    التنسيق + مخرج JSON
```
