# تثبّت | Tathabbut

أداة عربية للتحقق من الاقتباسات القرآنية والحديثية قبل النشر. يعرض كل ادعاء مع النص المسجّل ومصدره والفروق، ويحيل الحالات الشخصية إلى مختص.

- [الموقع المنشور](https://tathabbut.vercel.app)
- [المستودع](https://github.com/arifcoTeame/tathabbut)
- إصدار الكود الحالي: **0.7.0**. راجع [حالة التسليم](docs/SUBMISSION_CHECKLIST.md) و[سجل التطوير ونسخة البداية](docs/DEVELOPMENT_LOG.md).
- نص المصحف قوبل بمصحف حفص في الموسوعة القرآنية (طبعة مجمع الملك فهد): 6230 آية متطابقة و6 فروق إملائية فقط، والآيات الـ6236 بنص الطبعة كلها «موثّق» في المحرك. [التفاصيل](docs/QURAN_REFERENCE_CHECK.md).
- النطاق الحالي: **6236 آية و72 حديثاً** (12 سجلاً موروثاً + 60 سجلاً روجعت مع الدرر السنية في 3 أكتوبر 2026، انظر `docs/VERIFY_SEED.md`). نص القرآن المعروض والمطابَق هو نص مصحف حفص بطبعة مجمع الملك فهد من [الموسوعة القرآنية](https://quranpedia.net) (منذ 0.7.0). يتعرّف المحرك على الآية ولو كُتبت دون تشكيل أو همزات أو أقواس (مثل «قل هو الله احد» ← سورة الإخلاص، الآية 1). أي حديث لا يوجد في القاعدة يُعرض «لم يُعثر عليه ضمن قاعدة البيانات الحالية · يتطلب تحققاً»، وهو ليس حكماً بعدم الصحة.

## كيف يعمل؟

1. يستخرج الاقتباسات والادعاءات ويصنّفها بقواعد إلى المستويات أ–د.
2. يبحث في النصوص باستخدام BM25 وتمثيل TF-IDF حرفي مضغوط بـSVD؛ ثم يجمع الترتيبين بطريقة RRF.
3. يقارن ألفاظ الاقتباس بالمصدر دون استخدام التجذير لإثبات التطابق؛ يعرض الفروق كلمة بكلمة.
4. يصدر الحكم بقواعد من المطابقة ودرجة الحديث المسجّلة. لا يولّد درجة حديث.

الشرح الحالي قوالب نصية، ولا توجد خدمة نموذج لغوي توليدي في المسار الافتراضي. BGE-M3 خيار منفصل يحتاج تثبيتاً وموارد إضافية؛ لم يُستخدم لإنتاج نتائج التقييم الحالية.

## التشغيل

الخلفية:

```bash
cd backend
./setup.sh
source .venv/bin/activate
uvicorn app.main:app --reload --port 8000
```

الواجهة في نافذة أخرى:

```bash
cd frontend
npm ci
npm run dev
```

افتح `http://localhost:3000`. توثيق API على `http://localhost:8000/docs`.

الإعدادات من متغيرات البيئة؛ ملف `.env.example` دليل لها، ولا يحمّله Python تلقائياً. لبناء الفهرس أو تحديثه:

```bash
cd backend
.venv/bin/python scripts/build_index.py
```

في الإنتاج اضبط `TATHABBUT_REQUIRE_VERIFIED=true` كي لا يُعتمد سجل غير مراجع. عنوان الخلفية يضبط في الواجهة عبر `TATHABBUT_API_URL`.

## التحقق

```bash
cd backend
bash run.sh test                       # 163 اختباراً
.venv/bin/python scripts/evaluate_release.py --in-process --repeat 3 --output ../docs/evidence/local-smoke.json
.venv/bin/python scripts/compare_baseline_search.py        # مقارنة بالبحث الحرفي على الحالات نفسها
cd ../frontend
npm run typecheck
npm run build
```

`evaluate_release.py` مع `--in-process` يشغّل المحرك داخل العملية ويختبر 31 حالة محددة (×3 عند `--repeat 3`) ويحتفظ باستجاباتها؛ ومع `--base-url https://tathabbut.vercel.app --frontend` يختبر النسخة المنشورة. هذه الحالات مختارة لكشف أنماط الفشل، وليست قياساً لدقة عامة على الأحاديث المتداولة.

لمقابلة النص القرآني بحزمة الموسوعة القرآنية الرسمية: `scripts/compare_quranpedia.py` (انظر [QURAN_REFERENCE_CHECK](docs/QURAN_REFERENCE_CHECK.md)). لفحص جاهزية حزمة التسليم: `python3 scripts/check_submission.py` من جذر المستودع.

## معاني النتائج

| الرمز | العرض | المعنى |
|---|---|---|
| VERIFIED | موثّق | اقتباس مطابق؛ الحديث له درجة مقبولة مسجّلة |
| NOT_AUTHENTIC | لا يصح | نص مطابق لحديث ذي درجة ضعف أو وضع مسجّلة |
| ALTERED | مُحرّف | اقتباس قرآني قريب مع فرق لفظي ظاهر |
| NO_ORIGIN | لم يُعثر عليه ضمن قاعدة البيانات الحالية | يتطلب تحققاً؛ لا يحكم على صحة الحديث أو وجوده في مصادر أخرى |
| DISPUTED | خلافي | تعارض درجات مسجلة أو مسألة تتطلب عرض الخلاف والإحالة |
| REFER | إحالة | حالة شخصية تستلزم جهة مؤهلة |
| NEEDS_REVIEW | يتطلب مزيد تحقق | اختلاف لفظي أو بيانات لا تكفي لنقل الحكم إلى النص المدخل |

## الحدود

- المدخل نص حتى 4000 حرف، مع فحص حتى 12 مقطعاً مستخرجاً في الطلب؛ لا يوجد جلب صفحات أو صور أو صوت في هذا الإصدار.
- قاعدة الأحاديث صغيرة، ولا يمثل عدم العثور فيها حكماً بعدم وجود الحديث.
- يقبل تطبيع المطابقة التشكيل والوقف والمسافات وعلامة الوصل. لا يدّعي دعم جميع القراءات والرسم العثماني.
- كشف الحالات الشخصية مبني على أنماط لغوية؛ لا يضمن كشف كل صياغة أو كل اجتزاء يغيّر المعنى.
- درجات الأحاديث ومراجعتها الموروثة موثقة في [VERIFY_SEED](docs/VERIFY_SEED.md). ليست مراجعة شرعية مستقلة لهذا الإصدار.
