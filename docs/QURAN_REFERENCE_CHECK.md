# حالة المقابلة بالمصدر القرآني المذكور في المرجعية

آخر مراجعة: 4 أكتوبر 2026، بتوقيت الرياض.

- يحتوي المشروع 6236 آية من Tanzil، حفص، Simple Clean، مع نص الحقوق والرابط وحفظ النص الأصلي. فحوص بنية المجموعة وحفظ الألفاظ لا تعني مقابلة مستقلة مع طبعة أخرى.
- تذكر المرجعية العلمية للمنظم مجمع الملك فهد أو الموسوعة القرآنية. عُثر على [حزم الموسوعة الرسمية](https://quranpedia.net/dumps)، وفيها مصحف حفص النصي `mushafs-2.json.gz`، وإصدار معلن `2026-09-29` وبصمات ملفات.
- [الرخصة المنشورة](https://quranpedia.net/dumps/LICENSE.md)، النسخة `2026-10-02`، تتيح الاستخدام داخل التطبيقات وتطلب نسبة المصدر ورقم النسخة عند إعادة نشر قاعدة قابلة للتنزيل، مع متابعة التصحيحات. لا يحل ذلك محل تراخيص المصادر الخارجية الأخرى في الموسوعة.
- محاولة تنزيل ملف حفص الرسمي من هذه البيئة أعادت HTTP 403. لم نحصل على الملف، ولم نجر مقارنة كاملة، ولم نغير بيانات القرآن أو نزعم تطابقاً لم يُقَس.

## أداة المقابلة الجاهزة (4 أكتوبر)

أُضيف `backend/scripts/compare_quranpedia.py` مع 4 اختبارات. يأخذ ملف الموسوعة `mushafs-1.json.gz` (الحفص النصي، 394 KB، SHA-256 معلن في صفحة الحزم)، يتحقق من بصمته، ويقابل الآيات الـ6236 بعد إزالة التشكيل وتوحيد صور الهمزة، ثم يسرد كل فرق متبقٍ حرفياً للمراجعة البشرية دون تعديل بيانات المشروع:

```bash
cd backend
python scripts/compare_quranpedia.py ~/Downloads/mushafs-1.json.gz \
  --expected-sha256 fdfdfd8a01fbe9136309f53d300e4b1d1f358d06c5d1111804d819c906f41034 \
  --output ../docs/evidence/quranpedia-compare.json
```

في 4 أكتوبر أعادت بيئة العمل HTTP 403 مرة أخرى عند طلب الملف، فلم تُنفَّذ المقابلة بعد. تُنفَّذ من جهاز صاحب المشروع ويُحفظ الناتج في `docs/evidence/`.

## إجراء الإغلاق

1. تنزيل ملف حفص الرسمي وفهرس بصمته من الروابط المنشورة، دون تجاوز قيود الوصول.
2. التحقق من SHA-256 وحفظ تاريخ المصدر ورخصته؛ تثبيت السورة ورقم الآية ورواية حفص.
3. المقارنة آية بآية، مع فصل الاختلاف في الرسم والتشكيل عن اختلاف الحروف والكلمات. لا يُستخدم التطبيع الواسع لإخفاء اختلاف حقيقي.
4. مراجعة الفروق بشرياً، ونشر العدد والطريقة والحدود والنتيجة قبل وصف هذه المقابلة بأنها مكتملة.

تظل هذه البوابة مفتوحة. وجود ترخيص منشور ومسار تنزيل رسمي تقدم في تحديد المصدر، لكنه ليس دليلاً على اكتمال المقابلة.
