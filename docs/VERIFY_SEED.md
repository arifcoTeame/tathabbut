# مراجعة بيانات العيّنة قبل أي عرض عام

قاعدة المشروع: **لا يُصدر النظام درجة حديث من عنده**. لذلك كل سجل في
`data/seed/hadith_seed.json` يحمل `"verified": false` حتى تطابقه يدوياً مع
الدرر السنية، ثم تغيّره إلى `true`.

لكل سجل: افتح رابط البحث، وتحقق من (1) نص الحديث، (2) اسم المحدّث، (3) المصدر
والرقم، (4) خلاصة الحكم. صحّح أي اختلاف في الملف، ثم أعد بناء الفهرس.
