# نص القرآن الكريم

`quran_kfc.json` (المصدر المعتمد منذ الإصدار 0.7.0): نص مصحف حفص كاملاً (6236 آية) بالتشكيل،
موافق لطبعة مجمع الملك فهد لطباعة المصحف الشريف، من [الموسوعة القرآنية quranpedia.net](https://quranpedia.net)،
ملف `mushafs-1.json` إصدار 2026-10-04. يُنقل النص حرفياً (حُذفت المحارف غير المرئية فقط) بالسكربت
`backend/scripts/prepare_quran_kfc.py`. الرخصة وبيان المصدر في `LICENSES/Quranpedia.txt`.

`quran_full.json`: نص Tanzil.net بصيغة Simple Clean (دون تشكيل)، يُستخدم للمقابلة فقط
(`backend/scripts/compare_quranpedia.py`) ولا يُعرض للمستخدم. يُنقل حرفياً وفق [شروط Tanzil](https://tanzil.net/docs/text_license).
