# نص القرآن الكريم

`quran_full.json`: نص المصحف كاملاً (6236 آية) برواية حفص، بصيغة Simple Clean (دون تشكيل)،
مأخوذ من [Tanzil.net](https://tanzil.net) ومحوَّل بالسكربت `backend/scripts/fetch_quran.py` دون أي تعديل على النص.

يُستخدم النص وفق [شروط Tanzil](https://tanzil.net/docs/text_license): يُنقل حرفياً دون تغيير، مع الإشارة إلى المصدر.
